## 4. 当前 bug 修复清单（交接时必须保留）

以下是本轮当前 worktree 中已经修复、测试覆盖并供 Claude Code 复核的内容。不要回滚这些改动。

### A. agent/eval_pi_agentic.py

- agent_env() 为 pi 子进程补齐 /opt/conda/bin 和 /opt/conda/envs/spatialagent/bin，解决 ffmpeg/ffprobe 不在 PATH 导致 agent 反复失败的问题。
- Prompt 与实际工具一致，禁止模型用 which、whereis、find / 盲搜环境。
- _repair_swallowed_tool_calls 从贪婪正则改为按 </tool_call> 扫描并用 JSONDecoder 解码，支持嵌套 arguments 和连续 remnant calls。
- 被打捞的调用进入 tool_trace，使用 salvaged-* ID；只有与真实 tool_execution_end 匹配的 ID 才计入 tools_executed，避免把“解析出来”误报成“真正执行”。
- 只有 assistant message 中的 toolCall 计数，避免把 toolResult 或其他角色内容误计为模型调用。
- extract_answer 先做选项精确匹配，并屏蔽被长选项包含的短 substring，修复 Clockwise/Counterclockwise 误解析。
- 结果 JSONL 落盘 tool_trace、tool_results、tools_executed、tool_errors 和 closure 诊断，支持离线审计。

### B. agent/pi_ext/vistr_video_tools.ts

- read_video_sequence 拒绝非有限时间和 start_s > end_s，不再把反向区间静默压成重复帧。
- semantic_crop 视频输入缺 time_s、时间非有限时返回友好错误。
- read_multiframe 拒绝空/非有限时间戳。
