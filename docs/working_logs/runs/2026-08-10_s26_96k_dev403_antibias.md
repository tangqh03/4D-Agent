## 诊断重跑（超时题）

#1188/#1210 用同一 96k 服务单独重跑（`--workers 1 --timeout 900`），输出
`outputs/predictions/pi_s26_claude_retry_timeout_1188_1210_20260810.jsonl`：

| ID | 重跑 pred | GT | correct | elapsed | tools | infra |
|----|-----------|----|---------|---------|-------|-------|
| 1188 | Counterclockwise | Counterclockwise | ✓ | 291.6s | 13/13 | 0 error |
| 1210 | Counterclockwise | Clockwise | ✗ | 455.1s | 12/12 | 0 error |

两题重跑均正常完成（<900s），0 tool/provider error，终态 unresolved/verified=false。
结论：原全量中的超时是**瞬时 GPU 争用**（3 workers 挤占导致单样本 >900s），非确定性
模型卡死，可恢复。按协议不合并进正式 403 输出，官方文件该两行保留 `pred=null`。
若按重跑结果恢复，全量 accuracy 将升至 210/403 = 52.1%（#1188 修对、#1210 仍错）。
